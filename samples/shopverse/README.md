# ShopVerse

A full-stack e-commerce platform: Spring Boot REST API + React storefront + PostgreSQL.

- `backend/` — Spring Boot 3 (Java 21): auth (JWT), users, catalogue, cart, orders, payments (Stripe), inventory, reviews, admin reports
- `frontend/` — React 18 + TypeScript + Vite storefront
- `database/` — PostgreSQL schema

Run: `docker compose up`
